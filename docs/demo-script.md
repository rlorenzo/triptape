# Demo Script — Messy Folder to Magic (3 minutes)

Audience: hackathon judge with no setup help. Budget: 3 intentional clicks
plus the OS folder-picker confirm; the one-time consent "Got it" is counted
separately. Reels disclosure adds no click.

## Setup (before the clock)

1. `./scripts/make-fixture.sh /tmp/demo-trip` (tiny synthetic trip).
2. Open TripTape; confirm the Library is empty.

## The run

| Time | Click | What the judge sees |
| --- | --- | --- |
| 0:00 | **Click 1 — Add folder** | Pick `/tmp/demo-trip`, confirm the OS dialog. Grid fills in live with counts; ingest progress bar. |
| 0:20 | (consent, one-time) | "Got it" on the consent sheet — faces on-device, nothing uploaded. |
| 0:30 | — | Library: day/place groups, filters (day, place, people, best/all). |
| 1:00 | **Click 2 — Story** | Chapters by day with hero picks + "why this moment", editable captions, music pick. Change one caption live. |
| 1:45 | **Click 3 — Export all** | One button; video → reels → book render in sequence with per-card progress, time estimate, cancel. |
| 2:30 | — | Reveal in Finder/Explorer: hero MP4 plays, reels folder (with the share disclosure line on the card), book proof PDF + JPEGs. |

## Fallback

If a live render is slow on stage, play the pre-recorded capture of the
same fixture run and narrate the click budget over it.
